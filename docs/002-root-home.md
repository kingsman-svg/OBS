# 第 002 步：默认账号与媒体工作台

## 使用

Qt Creator 打开 CSN/CMakeLists.txt，重新构建并运行 CSN。账号 root（预填），密码 root（手动输入）。接口由启动时的本地开发服务自动填写，端口动态分配。
错误密码保留登录页；成功切换到媒体工作台；退出清空内存会话并返回登录页。主页显示下一步采集方向，采集功能尚未实现。

## 设计

新增 LocalAuthServer 类，与客户端共用 Qt 事件循环，HTTP 请求异步处理。仅监听 IPv4 本机地址；支持 Content-Length JSON POST /auth/login。请求头限 8 KiB、请求体限 16 KiB、总请求限 24 KiB，连接 5 秒到期，最多 16 个活跃连接，每次响应后关闭。
固定开发账号通过服务器验证，生成独立 UUID 临时令牌并返回既有契约。没有持久化、受保护 API 或服务端令牌校验，退出仍是本地清除会话。

MainWindow 保持一个 View 类，QStackedWidget 承载登录页和主页；LoginController、LoginModel 的职责保持原设计。新增类图、服务处理时序图，更新 View 类图、登录和退出时序图。

## 验证

新增测试覆盖 root 成功、错误密码、页面切换、退出和再次登录令牌变化，以及 HTTP 方法、路径、坏 JSON、重复长度、大小上限、分段请求。与既有网络及 MVC 测试一起执行。

Qt 6.11.2 / MSVC 2022 Debug 构建通过；CTest 通过（7 组行为检查）。登录后的页面截图为 out/主页页面.png。
